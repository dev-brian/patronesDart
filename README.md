# Patrones de Diseño en Dart

Ejemplos de patrones de diseño implementados en Dart.

## Patrones

| Patrón      | Carpeta      | Descripción                                          |
|-------------|--------------|------------------------------------------------------|
| Singleton   | `singleton/` | Garantiza una única instancia de una clase.          |

## Ejecutar

Desde la carpeta de cada patrón:

```bash
dart run
```
